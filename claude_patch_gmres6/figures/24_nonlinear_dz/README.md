## Configuration
Nonlinear_Boussinesq_Irk_SC.py --no_rotation -firedrake_1_snes_ksp_ew -firedrake_1_snes_ksp_ew_rtol0 1e-2 -firedrake_1_snes_atol 1e-09 --maxit 100 --patch <p> (its default solver): Newton (newtonls) with Eisenstat-Walker (PETSc v2, rtol_0 = 1e-2): the FGMRES tolerance of every Newton step is set by EW, so the script's --rtol 1e-6 is overridden; outer FGMRES (right, atol 1e-9, at most 100 iterations per Newton step, restart 30); IRKAuxiliaryOperatorPC with the shifted operator (pressure elimination p -> p - div(u)/delta); Schur fieldsplit, exact pressure-mass solve; ONE full-multigrid cycle on the velocity-buoyancy block with GMRES(6) + ASM column-patch smoothing, MUMPS/LU coarse; 2 MPI ranks.

Sweep: the paper's dz sweep (`Bash_Generator/bash_paper_patch.py --mode nonlinear --test dz`), delta = C1/dt with
C1 = 1e-05; members Nz=10 ... Nz=80;
dt in [1.0, 5.0, 10.0, 50.0, 100.0, 500.0, 1000.0, 5000.0, 10000.0, 50000.0] s.

Data (all paths relative to `yr2/`): `data/patch_gmres6/data_nonlinear_dz_deg2_ew_gmres6_star` and
`data/patch_gmres6/data_nonlinear_dz_deg2_ew_gmres6_vanka` (each run's command in `jobs/job_*/cmd.sh`, its log in
`jobs/job_*/run.log`, status in `jobs/job_*/status`; take C1 from the `# C1=` comment of cmd.sh or from counts.csv, not
from run.log, which prints shift*dt^1.5 under that name). Columns `old_*` in counts.csv are the 2026-10-16 runs in
`data/paper_robustness/data_nonlinear_dz_deg2_ew_star` etc.: the same solver configuration (GMRES(6), FGMRES-right, EW) run on 2026-10-16; differences are run-to-run noise, see ../40_repeatability_nonlinear/.

Counting: total FGMRES iterations over all Newton steps of the monitored time step (counts.csv also gives Newton steps);
`>=100` = a solve hit maxit 100 without converging; `div` = Newton/KSP diverged (job failed without output).
K = delta / delta_thr(dt) (claude_paper_shift.py): K < 1 is the regime where the grad-div term dt/delta dominates; it
occurs at large dt and small C1 (in these sweeps K does not depend on Lz for dt <= 1000 s, the weakly stratified branch).
rho1 = m Lz^2 / (pi^2 dx_fine^2), m = 1 + (dt N)^2/4, dx_fine = Lx / (4 Nx) (the 2026-09-29 study's kernel parameter).
