## Configuration
LB_time_slice.py --richardson --reordering --rtol 1e-8 --maxit 100 --mg_smoother gmres --patch <p>: outer FGMRES (right, true residual, rtol 1e-8); Schur fieldsplit with exact pressure-mass solve; shifted auxiliary operator for the velocity-buoyancy block solved by ONE full-multigrid cycle (3 levels, horizontal coarsening, MUMPS/LU coarse); level smoother GMRES(6) + additive Schwarz on column patches (ASMStarPC / ASMVankaPC, LU with RCM); f = 0; 2 MPI ranks.

Sweep: the paper's dt sweep (`Bash_Generator/bash_paper_patch.py --mode linear --test dt`), delta = C1/dt with
C1 in [1.0, 0.1, 0.01, 0.001, 0.0001, 1e-05]; members C1=1 ... C1=1e-05;
dt in [1.0, 5.0, 10.0, 50.0, 100.0, 500.0, 1000.0, 5000.0, 10000.0] s.

Data (all paths relative to `yr2/`): `data/patch_gmres6/data_linear_dt_deg2_gmres6_star` and
`data/patch_gmres6/data_linear_dt_deg2_gmres6_vanka` (each run's command in `jobs/job_*/cmd.sh`, its log in
`jobs/job_*/run.log`, status in `jobs/job_*/status`; take C1 from the `# C1=` comment of cmd.sh or from counts.csv, not
from run.log, which prints shift*dt^1.5 under that name). Columns `old_*` in counts.csv are the 2026-10-16 runs in
`data/paper_robustness/data_linear_dt_deg2_star` etc.: Chebyshev(6) smoothing with outer GMRES-left (preconditioned residual), so they are NOT the same solver; see ../30_smoother_linear/.

Counting: n = outer FGMRES iterations to rtol 1e-8 on the true residual; a run that meets rtol at exactly iteration 100 counts as converged (column *_converged_at_cap);
`>=100` = a solve hit maxit 100 without converging; `div` = Newton/KSP diverged (job failed without output).
K = delta / delta_thr(dt) (claude_paper_shift.py): K < 1 is the regime where the grad-div term dt/delta dominates; it
occurs at large dt and small C1 (in these sweeps K does not depend on Lz for dt <= 1000 s, the weakly stratified branch).
rho1 = m Lz^2 / (pi^2 dx_fine^2), m = 1 + (dt N)^2/4, dx_fine = Lx / (4 Nx) (the 2026-09-29 study's kernel parameter).
